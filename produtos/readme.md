## Descrição

Projeto desenvolvido em Python com o objetivo de controlar os produtos e o estoque de um almoxarifado, possibilitando o cadastro de itens, a consulta de quantidades disponíveis, o registro de entradas e saídas, o cálculo do valor total dos produtos armazenados e a criação de pedidos de reposição.
## Como executar os testes

No terminal, dentro da pasta principal do projeto, execute:

`py -m testes.teste_almoxarifado`
